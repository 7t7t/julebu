CET6 六级阅读终极技巧手册（可直接复制背诵）
纯应试、定位为王、答案秒选。
一、六级阅读核心原则（先背这 4 句）
答案 100% 来自原文，不推理、不脑补、不靠常识。
题干关键词 = 定位钥匙，找到句子 = 找到答案。
正确选项 = 原文同义替换，几乎不改变原意。
错误选项 90% 有明显特征，一眼排除。
二、最实用：快速定位答案句方法

1. 定位词怎么选？（必背）
   优先找不会被改写的词：
   大写：人名、地名、机构、书名
   数字 / 年代 / 百分比
   特殊符号：连字符、引号词
   长难名词 / 专业词
   动词、形容词慎用（最容易被替换）
2. 定位黄金顺序
   看题干 → 圈 2–3 个定位词
   回原文从上往下扫，找到词所在句
   答案 90% 在本句 / 下一句，极少在上一句
3. 从答案反推定位句（高分技巧）
   如果你找不到原文：
   看选项里最独特的名词 / 大写 / 数字
   用它回原文找
   找到后再对照题干，确认是否对应
   三、六级阅读题型 + 答案位置 + 关键词
4. 细节题（占 60%）
   特征：what / why / how / which / according to…答案位置：
   定位词所在句
   下一句（常是答案）
   信号词（答案就在后面）
   because / due to / therefore / thus / so
   but / however / yet / although
   in fact / actually
5. 主旨题 / 标题题
   答案位置：
   第一段首尾
   每段首句串读
   最后一段总结
   绝对不选：太细节、太片面、范围太大
6. 推理题（infer /imply/suggest）
   记住：不许推！
   正确答案：原文最直接的同义改写
   错误：过度推断、主观评价、常识干扰
7. 态度题
   答案常出现在：
   形容词 / 副词
   but /however 后
   结尾段
   常见态度：
   positive / negative / neutral / critical / supportive / concerned
8. 词义题 / 指代题
   答案一定在上下文：
   本句前后找同义 / 反义
   看并列结构、定语从句
   代入法最稳
   四、正确选项特征（看到直接选）
   同义替换（最典型）
   important → vital /crucial
   many → a number of /numerous
   change → transform /alter
   语气委婉
   may / might / possible / some / not necessarily
   概括性强，不绝对、不偏激
   与题干逻辑一致（因果、目的、条件）
   五、错误选项特征（看到直接排除）
   绝对词（99% 错）
   must /never/always /all/only /entirely/completely
   比较级慎选！
   more /better/less /higher/increasingly
   原文没明确比较，选项一比较 → 错
   无中生有
   原文没提，常识对也错
   偷换概念
   主体换了、对象换了、程度换了
   拼凑原文
   词都见过，但逻辑乱拼
   反向干扰
   支持 ↔ 反对，增加 ↔ 减少
   六、考场救命：答案句高频信号词
   只要出现，80% 是答案区：
   转折（最重要）
   but /however/yet /although/while /nevertheless
   因果
   because / since / therefore / thus / lead to / result in
   解释 / 强调
   in fact / actually / that is / namely
   对比
   rather than / instead of / not… but…
   观点
   believe / argue / suggest / claim / point out
   特殊结构
   not only…but also…
   more…than…
   七、阅读做题标准步骤（100% 提分）
   先看题干，圈定位词，不看选项
   回原文快速扫读定位，找到句子
   精读定位句上下各一句
   对比选项：
   同义替换 → 对
   绝对 / 比较 / 拼凑 → 错
   不纠结，不重读，不回看
   八、你特别要记的：比较级慎选规则
   原文没有明确比较，选项出现：
   more /better/worse /higher/lower /increasingly
   直接排除！
   只有原文明确：A is better than B
   选项才可能对
   九、极简口诀（背完直接上考场）
   定位找准大写数，答案就在转折处。同义替换是正解，绝对比较要慎入。不推不猜不脑补，原文一句定胜负。

   一、最高频动词替换（必考）
   认为think / believe → argue / claim / suggest / maintain / insist
   强调stress → emphasize / highlight / underline
   导致cause → lead to / result in / contribute to / bring about
   解决solve → resolve / address / tackle / cope with
   提高 / 改善improve → enhance / promote / boost / raise
   减少reduce → decrease / decline / cut down
   促进help → facilitate / promote / advance
   表明 / 显示show → indicate / reveal / demonstrate
   二、形容词 / 副词替换（答案最爱）
   重要的important → vital / crucial / critical / essential
   足够的enough → adequate / sufficient
   普遍的common → widespread / universal
   显著的obvious → apparent / remarkable / significant
   可能的possible → likely / potential
   三、名词替换
   方法 / 方式way → approach / method / means
   结果result → consequence / outcome
   原因reason → factor / cause
   目的purpose → aim / goal
   优势advantage → strength / merit
   四、逻辑 / 范围替换（定位神词）
   许多many → numerous / a number of / multiple
   越来越more and more → increasingly / growingly
   五、同义替换秒选口诀（背这 4 句）
   题干原文长得越像，越容易是坑
   选项和原文换词不换意，90% 是答案
   绝对词不选，比较级慎选
   同义替换一出，直接锁定

   10 大错误选项标志 + 10 秒排除法（纯 Markdown，可直接复制）
   一、10 大错误选项标志（看到直接排除）
9. 绝对词（99% 错）
   must、always、never、all、only、entirely、completely、absolutely
   只要出现，直接排除
10. 比较级 / 最高级（慎选！）
    more、better、worse、less、higher、lower、increasingly、most
    原文没有明确比较，选项出现比较 → 错
11. 无中生有
    原文完全没提到的内容
    常识再对、逻辑再通顺，没提 = 错
12. 偷换主体 / 对象
    原文讲 A，选项讲 B
    原文讲对学生，选项变成对所有人
    主体一换，直接错
13. 扩大 / 缩小范围
    原文：some（一些）
    选项：all /most（全部 / 大多数）→ 错
    原文：certain area
    选项：the whole country → 错
14. 反向干扰（正反颠倒）
    原文：increase 上升
    选项：decrease 下降
    原文：support 支持
    选项：oppose 反对
    必错
15. 拼凑原文（词都对，逻辑错）
    单词都来自原文，但句子重新乱拼
    长得最像原文的，往往是坑
16. 过度推理（infer 题最爱挖坑）
    infer/imply 题：
    正确：原文直接改写
    错误：自己脑补、延伸、推测
    只要多推一步，必错
17. 细节当主旨（主旨题专属坑）
    主旨题里，选项只是某一段细节
    看似正确，实则片面 → 错
18. 态度过于极端
    选项：
    indifferent（漠不关心，几乎不选）
    biased /prejudiced（有偏见，很少对）
    radical /arbitrary（极端 / 武断，基本错）
    二、10 秒排除法（考场直接用）
    先扫绝对词：must/only/never/all → 删掉
    再扫比较级：more/better/best → 慎选
    看是否原文有：没提 → 删掉
    看主体是否一致：不一致 → 删掉
    看方向是否相反：相反 → 删掉
    剩下 1–2 个，回原文同义替换核对
    三、最简口诀（背这一段）
    绝对比较先排除，无中生有最可恶。偷换主体别迷糊，拼凑原文是套路。正反颠倒直接否，过度推理别踏入。同义替换才是正主，对照原文不迷路。
