二、精听训练四步法（整合新东方 / 考虫 / 文都名师核心技巧）

1. 盲听模考（1 遍・原速）
   不看文本，完整听 1 遍，抓5 要素：人 / 事 / 时间 / 地点 / 态度
   技巧：首句 + 尾句 = 主旨，转折词后是答案（but/however/actually）
2. 逐句精听（2–3 遍・可暂停）
   一句一停，听写关键词；听不懂反复放
   技巧：视听一致（听到什么优先选什么）；绝对词慎选（always/never/only）
3. 倍速强化（1 遍・1.25x）
   用 1.25 倍速过一遍，适应考场快节奏
   技巧：符号速记 → ↑上升 /↓下降 /prof 教授 /gov 政府
4. 跟读复盘（1 遍・原速）
   影子跟读，模仿连读 / 弱读 / 重读
   标记：生词、连读、漏听点
